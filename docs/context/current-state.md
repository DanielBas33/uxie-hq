# UXIE — Current State

> Last updated: 2026-09-27

## Current stage

UXIE is in an early stage.

The immediate objective is to obtain the first real UXIE projects, validate the offer in the market and start building a credible portfolio.

At this stage, maximizing margin is secondary to:

- gaining real projects
- learning from clients
- validating the service offering
- generating case studies
- building reusable experience

UXIE may accept initial projects at less attractive pricing when the project provides meaningful strategic value.

## Current positioning

UXIE is currently focused on two main areas:

- AI and business automation
- digital experiences, UX/UI and modern websites

Backend, integrations, cloud and custom software are supporting capabilities, not the main public-facing offer.

## Current priorities

1. Get the first UXIE projects.
2. Validate which services generate real client interest.
3. Build a credible portfolio from delivered work.
4. Improve UXIE positioning and commercial messaging based on real feedback.
5. Build UXIE HQ as a useful internal knowledge base.
6. Continue improving practical AI, automation and digital-experience capabilities.
